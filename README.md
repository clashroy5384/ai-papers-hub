## 🛠 Features

*   **Search and Filter:** Find papers by topic, keyword, or date.
*   **Reading Library:** Save papers to a personal list for later review.
*   **Study Notes:** Use the built-in text editor to create summaries for every paper you read.
*   **Topic Tracking:** Follow specific fields like machine learning, computer vision, or natural language processing.
*   **Offline Access:** Download papers to your computer to read them without an internet connection.

## 📔 User Guide

### Browse Papers
When you open the app, you see a list of recent research papers from sources like arXiv. Use the sidebar to click on specific topics like "deep learning" or "reinforcement learning." 

### Organize Library
Click the "Bookmark" icon next to any paper title to add it to your personal library. You can create different folders inside the app to group papers by project or research goal.

### Create Notes
Open any paper in your library to use the "Create Note" feature. This opens a simple text box. You can write your own summary, copy key formulas, or note down findings. The application saves these notes with the paper file. 

### Syncing
The app stores your library data in a local folder on your drive. You can choose this folder in the "Settings" menu. If you back up this folder to a cloud service, you can keep your data safe.

## 🚧 Solving Common Issues

*   **App fails to open:** Make sure you downloaded the `.exe` file. Restart your computer if the installer hangs.
*   **Cannot find papers:** Check your internet connection. The app needs a connection to pull the latest listings from online repositories.
*   **App looks small or blurry:** Go to your Windows Display Settings and check your "Scale and layout" percentage. Setting this to 100% or 125% often fixes display issues.
